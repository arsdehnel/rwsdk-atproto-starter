rwsdk + AT Protocol Starter

A starter kit for building AT Protocol applications on RedwoodSDK and Cloudflare Workers.

This is the companion code for a blog series that walks through building a real AT Protocol app from scratch.

The series

Each branch is the complete, working state of the code at the end of that post.

  1. Your First AT Protocol Read — post/01-first-read
  2. AT Protocol OAuth with rwsdk — post/02-oauth
  3. Local Development with Docker Compose — post/03-devnet
  4. Lexicons and Writing to Your PDS — post/04-lexicons
  5. Reacting to Changes with Tap and Jetstream — post/05-tap-sync
  6. Persistence with D1 and Drizzle — post/06-d1-persistence
  7. Building a Feed — You're an AppView Now — post/07-appview
  8. Where to Go From Here — post/08-next-steps

What you'll end up with

  • rwsdk app running on Cloudflare Workers + Vite
  • AT Protocol OAuth login against real Bluesky accounts or a local devnet
  • Typed record reads and writes via a lexicon client
  • Webhook-driven updates via Tap — no polling
  • Data persistence with Cloudflare D1 and Drizzle ORM
  • Full local devnet via Docker Compose

Get started

git clone https://github.com/arsdehnel/rwsdk-atproto-starter
cd rwsdk-atproto-starter
pnpm install
pnpm dev

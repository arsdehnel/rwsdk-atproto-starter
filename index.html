rwsdk + AT Protocol Starter

A starter kit for building AT Protocol applications on RedwoodSDK and Cloudflare Workers.

This is the companion code for a blog series that walks through building a real AT Protocol app from scratch.

The series

Each branch is the complete, working state of the code at the end of that post.

Step Title Intro Blog Post Git Branch
1 First Read Fetch and display public AT Protocol records without authenticating First Read post/01-first-read
2 AT Proto OAuth Wire up OAuth login against a real Bluesky account AT Proto OAuth post/02-atproto-oauth
3 Local Dev Setup Run a full AT Protocol PDS and PLC locally in Docker — no prod dependency Local Dev Setup post/03-local-dev-setup
4 AT Proto Writes Define a lexicon, codegen TypeScript types, and write records to your PDS AT Proto Writes post/04-atproto-writes
5 Tap Sync React to new records in real time using Tap webhooks and SSE Tap Sync post/05-tap-sync
6 D1 Persistence Swap in-memory state for D1 and Drizzle so data survives a restart D1 Persistence post/06-d1-persistence
7 AppView Index records from multiple users and serve a public status board AppView post/07-appview
8 Next Steps What's left open, what to harden before going further, and where to take it Next Steps post/08-next-steps

What you'll end up with

  • A working rwsdk app built for Cloudflare Workers, running locally via Vite
  • AT Protocol OAuth login — against a local PDS in dev, or a real Bluesky account when you point it there
  • Typed record reads and writes via a lexicon client
  • Real-time record updates via Tap webhooks and SSE
  • State that survives a restart with Cloudflare D1 and Drizzle ORM
  • A full local dev stack via Docker Compose so you never have to touch prod infrastructure

Get started

This will get you the end result. Change to whatever branch you want for the step you're digging into. 

git clone https://github.com/arsdehnel/rwsdk-atproto-starter
cd rwsdk-atproto-starter
pnpm install
pnpm dev
